One query. Two response formats.

QUERY carries read-only query input in a request body. It is safe and idempotent. JSON returns the full result; SSE delivers events over time.

1. A single JSON response

Your result will appear here.

2. An SSE response, read with Fetch

The client reconnects with Last-Event-ID. Each connection continues through the same 30 fixed readings. Options are captured when you press Start.

Stream events will appear here.

fetch() resolves on headers. response.json() waits for the whole body; a body reader waits for chunks. A chunk can contain half an event, several events, or half a UTF-8 character.

This client implements reconnection and replay explicitly. That is separate from an HTTP client's transparent retry of an idempotent request. Native EventSource cannot send this QUERY body.
